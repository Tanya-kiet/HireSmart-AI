# 📖 Overview

HireSmart AI is an AI-powered recruitment platform that helps recruiters automate resume screening, evaluate candidates intelligently, manage hiring pipelines, and improve recruitment decisions.

The platform provides separate experiences for **Recruiters** and **Candidates**, creating an end-to-end hiring ecosystem.

Instead of manually reviewing hundreds of resumes, recruiters receive AI-assisted candidate insights, transparent match analysis, and organised hiring workflows.

---

# 🎯 Problem Statement

Recruiters often spend hours manually reviewing resumes, tracking applicants, scheduling interviews, and managing hiring pipelines.

Traditional recruitment systems suffer from:

- Manual resume screening
- Time-consuming candidate evaluation
- Poor applicant tracking
- Lack of explainable AI recommendations
- Inefficient hiring workflows
- Fragmented recruitment tools

HireSmart AI addresses these challenges by providing a modern, intelligent recruitment platform.

---

# 💡 Solution

HireSmart AI combines Machine Learning with an enterprise recruitment workflow to:

- Automatically analyse resumes
- Predict candidate domains
- Assist recruiters during screening
- Organise applicants through hiring pipelines
- Improve hiring efficiency
- Deliver explainable AI recommendations

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Tanya-kiet/HireSmart-AI.git
```

```bash
cd HireSmart-AI
```

---

## Backend

Create Virtual Environment

```bash
python -m venv .venv
```

Activate

```bash
source .venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Backend

```bash
python -m uvicorn backend.app.main:app --reload
```

---

## Frontend

```bash
cd frontend
```

Install Packages

```bash
npm install
```

Run

```bash
npm run dev
```
